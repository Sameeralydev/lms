# Phase 12 Performance Report

Latest local Vite build transformed 674 modules and emitted about 363.10 kB application JS (about 113 kB gzip) in about 4.09 seconds on local Windows. This is not production performance evidence.

Not measured: production LCP/INP/CLS; MySQL query plans, lock waits or throughput; large question-bank pagination; pool assembly under load; autosave/queue throughput; analytics latency. No production SLA/scalability claim. DB measurements are blocked by the missing guarded test environment.
